# EBSUMSA-EBSU

Ebonyi State University Medical Students Association Platform

Ebonyi State University Medical Students Association (EBSUMSA)  
Ebonyi State University, Abakaliki

---

# Overview

**EBSUMSA-EBSU** is a centralized digital platform designed for medical students of Ebonyi State University.

The platform serves as a digital hub where medical students can access academic resources, important updates, and tools that support their learning journey.

---

# Problem

Medical students often struggle to access essential academic materials in one place. Resources such as:

- Lecture notes
- Past questions
- Academic guidelines
- Important announcements
- Study tools

are usually scattered across multiple platforms or physical sources, making it difficult for students to stay organized and informed.

---

# Solution

The **EBSUMSA Platform** provides a centralized system that allows medical students to easily access the tools and resources they need.

### The platform provides:

- **Learning Resources**  
  Access to lecture materials, textbooks, manuals, and academic files.

- **Past Questions Repository**  
  Download previous examination questions to help students prepare.

- **Academic Blog**  
  Educational articles, medical insights, and updates for students.

- **Student Dashboard**  
  A personalized workspace where students can manage their learning activities.

- **Announcements & Notifications**  
  Important information from the association and department.

---

# Overall Benefits

- Easy access to academic materials
- Organized learning environment for students
- Reduced stress in finding study resources
- Improved academic preparation

The platform aims to support the academic success of medical students while strengthening the digital presence of EBSUMSA.

Navigate to the project directory

cd ebsumsa-ebsu

Install dependencies

npm install

Run the development server
